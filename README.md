# Email Verifier

Простая утилита на Go для проверки email-доменов: MX, SPF и DMARC-записи.

## Что делает

Принимает домены (по одному на строку) и для каждого выводит:

- `hasMX` — есть ли MX-записи (домен принимает почту);
- `hasSPF` — есть ли SPF-запись;
- `spfRecord` — сама SPF-запись, если найдена;
- `hasDMARC` — есть ли DMARC-запись;
- `dmarcRecord` — сама DMARC-запись, если найдена.

## Требования

- Go 1.20+

## Запуск

```bash
go run main.go
```

Программа ждёт ввод. Введи домен и нажми Enter.

Пример:

```
mailchimp.com
google.com
github.com
```

## Пример вывода

```
mailchimp.com, true, false, , true, v=DMARC1; p=reject; rua=mailto:...
```

Порядок колонок: `domain, hasMX, hasSPF, spfRecord, hasDMARC, dmarcRecord`.

## Как это работает

- `net.LookupMX` — ищет MX-записи домена.
- `net.LookupTXT` — ищет TXT-записи: сначала для SPF (`v=spf1`), потом для DMARC на `_dmarc.<домен>` (`v=DMARC1`).
- `strings.HasPrefix` — определяет, какая запись перед нами.
- Результат печатается в CSV-подобном виде.

## Возможные проблемы

**`DNS operation refused`** — DNS-сервер отказал в ответе. Решается сменой DNS на `8.8.8.8` (Google) или `1.1.1.1` (Cloudflare), либо отключением VPN/антивируса, перехватывающего DNS.

**`hasSPF = false`, но домен точно использует SPF** — вероятно, DNS не ответил на TXT-запрос. Ошибка логируется выше строки вывода.

## Что можно улучшить

- Отдельная колонка `error` — чтобы отличать «нет записи» от «ошибка запроса».
- Цветной вывод или таблица.
- Флаг для чтения доменов из файла.
- Параллельная проверка доменов через горутины.
